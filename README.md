# Протокол разногласий из правок Word

Это локальное приложение на Python: его окно открывается в браузере, а результат сохраняется как документ Word по вашему шаблону. Договор обрабатывается только на этом компьютере — приложение слушает соединения только на `127.0.0.1` и не отправляет файлы в интернет.

## Запуск

1. Дважды щёлкните `Запустить.bat`. Файл запускает локальную копию Python, доступную в этом окружении Codex.
2. Если браузер не открылся автоматически, перейдите по адресу `http://127.0.0.1:8765`.
3. В открывшейся вкладке выберите договор `.docx` или перетащите его на область загрузки.
4. Проверьте поля, отметьте нужные пункты и нажмите «Создать протокол по шаблону».
5. Файл `Протокол разногласий.docx` появится в папке загрузок браузера; откройте его в Word.

Закройте окно консоли, чтобы остановить приложение. Для работы рядом с программой должен находиться `шаблон_протокола_разногласий.docx`.

Приложение использует только стандартную библиотеку Python и не требует установки дополнительных пакетов. Если локальная копия Python из Codex недоступна, откройте эту папку в Codex и запустите файл ещё раз.
